# Clinic Booking API

An ASP.NET Core Web API for managing clinic bookings, patients, doctors, specialties, and appointments.

## Live Demo

- **Website:** http://alextechboxclinic.runasp.net/
- **Swagger UI:** http://alextechboxclinic.runasp.net/swagger

## Features

- Patient registration and management
- Doctor and clinic management
- Specialty management
- Appointment and booking management
- SQL Server database integration
- Stored procedures for database operations
- RESTful API endpoints
- API documentation using Swagger

## Technologies

- ASP.NET Core Web API
- C#
- SQL Server
- ADO.NET
- Swagger / OpenAPI

## Testing the API

1. Open the Swagger UI link above.
2. Select an endpoint.
3. Click **Try it out**.
4. Enter the required request data.
5. Click **Execute** to test the endpoint.
